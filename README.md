# CyberShield v1.0 – TCP Port Scanner

## About the Project
CyberShield is a beginner-friendly cybersecurity project developed using Python. It helps explore TCP port scanning and understand basic network security concepts.

## Features
- TCP port scanning
- Introduction to network ports and services
- Hands-on cybersecurity learning

## Technologies Used
- Python
- Socket programming
- Kali Linux / Linux (if used for development)

## Purpose
This project was created to improve my Python programming and learn practical cybersecurity fundamentals.
